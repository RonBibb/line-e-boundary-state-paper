# E1-FG1 Exact Fuchsian and Geometric Benchmark Result

**Date:** 2026-08-09  
**Test ID:** `E1-FG1`  
**Original machine classification:** `E1-FG1-NONCLOSURE`  
**Governing adjudicated classification:**
`E1-FG1-FUCHSIAN-GEOMETRIC-A-R`

## 1. Original machine outcome

The exact multi-mode Bessel benchmark executed successfully. Eight of nine
frozen gates passed. The sole machine failure was

```text
FUCHSIAN_data_depth_decreases = false
```

because the exact Fuchsian arm used analytic singular data and therefore had

\[
\delta v_P=delta v_\phi=delta P_\infty=delta\phi_\infty=0
\]

at depths 8, 12, and 16. An identically zero error cannot satisfy a strict
decrease. This was a specification-logic defect, not a scientific failure.

The original machine result and classification are preserved.

## 2. Exact solution tested

Each nonzero Fourier mode has the exact form

\[
f_k(\tau,\theta)
=\left[A_kJ_0(ke^{-\tau})+B_kY_0(ke^{-\tau})\right]T_k(\theta),
\]

with analytic asymptotic data

\[
v_k=-\frac{2B_k}{\pi},
\qquad
f_{\infty,k}=A_k+\frac{2B_k}{\pi}
\left(\log(k/2)+\gamma\right).
\]

Two modes were included independently in \(P\) and \(\phi\), together with
nonzero homogeneous velocities. The exact geometric data included

\[
q=v_P^2+v_\phi^2,
\qquad
\lambda_\infty'=2(v_PP_\infty'+v_\phi\phi_\infty'),
\qquad
c_\lambda=0.4.
\]

Periodic compatibility closed between exact zero and
\(2.84\times10^{-16}\).

\[

global anchor.

## 5. Scientific interpretation

The benchmark establishes, for an exact multi-mode polarized
Einstein–scalar solution, that:

1. the E1 singular functions coincide with the analytic Fuchsian two-term
   data;
2. reconstruction from exact singular data converges at second order to the
   analytic solution;
3. finite-window extraction converges rapidly toward those exact data;
4. the asymptotic momentum compatibility condition is correct;
5. \(\lambda_\infty\) and \(c_\lambda\) reconstruct the geometric metric
   sector consistently; and
6. the scale–shape decomposition survives a known-answer analytic benchmark.

This supplies the direct comparison with Fuchsian methodology and geometric
singular data that Paper E1 previously lacked. It remains a model-specific
numerical benchmark, not a replacement for weighted-Sobolev well-posedness
theory.
